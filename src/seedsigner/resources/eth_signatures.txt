# Extended Ethereum function-signature hints (UNVERIFIED) -------------------
#
# One canonical function signature per line. Loaded lazily by
# helpers/ethereum/signature_db.py to give more contract calls a
# human-readable name during signing.
#
# TRUST: these are *unverified hints*. The decoder labels them "(unverified)",
# the ERC-8213 / EIP-712 digests stay the source of truth, and a selector that
# matches more than one signature is shown as ambiguous, not guessed. Selectors
# are computed via keccak(signature), so a typo just yields a dead entry, never
# a wrong-but-confident decode. Entries already in the curated registry are
# ignored (the trusted name wins).
#
# TO EXTEND with the full 4byte directory (or any larger dump), drop a file
# named  eth_signatures.txt  on the microSD card (same one-signature-per-line
# format). It is merged on top of this baseline, capped for RAM, and likewise
# treated as unverified. Comments (#) and blank lines are ignored.
#
# Format rules: canonical types only, NO spaces, full type names (uint256 not
# uint). Supported: address bool uint<N> int<N> bytes string bytes<N> arrays
# tuples.
