# SeedSigner-Plus Smartcard Pico Enclosure

![SeedSigner-Plus smartcard Pico case and hat](./plus-picozero-hat.jpg)

3D-printable enclosure for the [SeedSigner-Plus smartcard Pico hat](../../../electronics/SeedSigner-Plus-smartcard-luckfoxpicozero/readme.md) (Luckfox Pico Mini).

## Hardware

- **2x M2 6–8 mm screws** — hold the camera module in place.

## Choosing the right parts

Which body and faceplate you need depends on your build:

- **Main body** — use the `BODY-Soldered` STL if the Pico Mini is soldered directly onto the PCB, or the `BODY-PINHEADER` STL if it sits on an 11-pin 2.54 mm pin header.
- **microSD cover** — match the body: `Microsd cover soldered` for a soldered build, `MicroSD cover PINEHEADER` for a pin-header build.
- **Faceplate** — depends on the board version: `Faceplate 1.0.1` for board v1.0.1, or `Old Faceplate 1.0.0` for the original v1.0.0 beta board.

## Notes

The case fits **low-profile** Pico Mini camera modules; full-sized camera modules will not fit.
